# lumina-library-sdp
📚 Lumina Library – Library Management System

Lumina Library is a library management system developed as part of my Software Development Project (SDP). The system is designed to make library operations easier by helping manage books, members, and loan transactions in one place.

Features include:

•Book management and status tracking
• Member registration and management
•Book borrowing and returns
• Overdue fines tracking
•Weekly and monthly reports

This project has helped me apply my software development skills, gain practical experience, and understand how to build a system that solves real-world problems.
